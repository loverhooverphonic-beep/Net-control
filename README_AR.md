# Net Control Android V1

مشروع أولي لتطبيق Android بواجهة داكنة، مخصص للاستخدام على الشبكة المحلية مع TP-Link TD-W8901N V3.

## الموجود في هذه النسخة
- شاشة داكنة باللغة الإنجليزية.
- عنوان الراوتر الافتراضي `http://192.168.1.1`.
- حقلا اسم المستخدم وكلمة المرور؛ لا يحفظ التطبيق كلمة المرور في التخزين الدائم.
- فتح واجهة إدارة الراوتر داخل التطبيق.
- فحص محلي تجريبي للأجهزة على النطاق `192.168.1.1` إلى `192.168.1.254`.
- قراءة جدول ARP المتاح للنظام إن سمح Android بذلك.
- تحديث تلقائي كل 10 دقائق أثناء بقاء التطبيق مفتوحا، وزر Scan now للتحديث اليدوي.

## قيود مهمة
1. فحص الشبكة المحلي لا يضمن ظهور كل الأجهزة؛ Android وبعض الأجهزة قد تمنع اكتشافها أو إظهار MAC. للحصول على قائمة DHCP الأدق، افتح صفحة الراوتر وانتقل إلى **Interface Setup > LAN > DHCP Table**. وللأجهزة اللاسلكية، افحص **Status > Device Info**.
2. دليل TP-Link يوضح أن جدول DHCP يعرض Hostname وIP وMAC، وأن صفحة Device Info تعرض عدد وعناوين عملاء Wi-Fi.
3. هذه النسخة لا تنفذ الحظر أو تحديد السرعة تلقائيا بعد. يجب اختبار بنية صفحات وإجراءات تسجيل الدخول للبرنامج الثابت الموجود على الراوتر قبل إضافة هذه الأوامر.
4. تحديث العشر دقائق يعمل أثناء فتح التطبيق فقط؛ Android قد يوقف النشاط في الخلفية. لم نضف خدمة خلفية مستمرة في هذه النسخة.
5. الاتصال بواجهة الإدارة يستخدم HTTP إذا كان الراوتر مضبوطا على HTTP. استخدم التطبيق على شبكة Wi-Fi المنزلية فقط، ولا تشارك بيانات دخول الراوتر.

## فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `NetControl_Android_V1` في Android Studio.
3. اسمح لـ Gradle بمزامنة المشروع.
4. صِل هاتف Android وفعّل USB debugging، أو استخدم محاكي Android.
5. اضغط Run.

المشروع مصدر Android Studio وليس APK جاهزا. يتطلب بناء APK باستخدام Android Studio/Android SDK.
